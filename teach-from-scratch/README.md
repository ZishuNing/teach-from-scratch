# teach-from-scratch

A skill for learning a system by **building** it from nothing — not by touring a finished one. One brick at a time: put a brick down, run it, feel what it can't do yet, put the next brick down. The learner never sees a component they cannot yet motivate.

Stateful by design: the build spans multiple sessions, tracked in `BUILD-PLAN.md`, with one self-contained HTML file per step.

## How it works

1. **Intake** — pick the target (a repo, a paper, a spec), the gear (paper or code, simplified or full), the practice form, and where the code lives.
2. **Teardown** — the target is torn down into a full chain of steps before anything gets built. Each step names the gap that hands off to the next.
3. **Build one step** — exactly the next unbuilt step, ending on an observable result and the gap it leaves behind.
4. **Close the step** — update the plan, distil reference material, record preferences. Repeat.
